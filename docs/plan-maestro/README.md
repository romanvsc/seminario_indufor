# Plan maestro de INDUFOR

<!-- plan-schema: 1 -->

Este plan enlaza antecedentes y revisiones pendientes. Las fuentes históricas conservan sus estados y trazabilidad; una tarea pendiente de revisión no implica que el trabajo original no exista. Estados verificados el 2026-11-04 con Pest y Vitest en verde (DEC-2026-11-04-08); la E2E de Playwright no se reejecutó.

Por pedido del usuario del 2026-11-04, registrar en este plan las tareas derivadas de sus solicitudes de aquí en adelante, con su estado y evidencia. El flujo vigente es [ODD](../../ODD.md); cuando una tarea requiere continuidad, enlaza su documento `odd/tasks/` sin duplicar estados en otro tablero. Un pedido expresamente de solo lectura permanece sin escrituras.

- [Antecedentes de construcción](00-preparacion.md): fases 1–7, documentadas en `docs/fases.md`.
- [Requerimientos funcionales RF01–RF16](02-requerimientos-funcionales.md): alcance y trazabilidad histórica por requisito; pendientes de verificación actual.
- [Requerimientos no funcionales RNF01–RNF05](03-requerimientos-no-funcionales.md): verificaciones y límites de evidencia.
- [Seguimiento SDD histórico](01-seguimiento-sdd.md): ocho especificaciones y evidencia en `specs/`, conservadas como antecedentes.
- [Auditorías de interfaz](04-auditorias-ui.md): hallazgos UI/UX propuestos para corregir.
- [Metodología de trabajo](05-metodologia.md): transición a ODD y memoria compartida.
- [Ficha](../proyecto.md), [arquitectura](../arquitectura/README.md) y [decisiones](../decisiones/README.md).

Usar el [esquema común](../../.agents/skills/plan-maestro-desarrollo-sistema/references/plan-schema.md); no duplicar reglas o decisiones de negocio. Ver [guía del visor](../../tools/visor-plan/README.md) para comandos, límites y actualización.
