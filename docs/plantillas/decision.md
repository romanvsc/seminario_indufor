# Plantilla de decisión

Crear el registro en `docs/decisiones` y enlazarlo desde su índice y las tareas afectadas. Para una pregunta pendiente, mantener Estado pendiente y no completar la respuesta por inferencia.

```markdown
# DEC-AAAA-MM-DD-NN — Asunto

- Estado: pendiente / confirmada / sustituida
- Fuente y responsable de la decisión:
- Problema y contexto:
- Alternativas relevantes y sus consecuencias:
- Decisión confirmada, si existe:
- Alcance, contratos y tareas afectados:
- Evidencia o motivo:
- Sustituye / sustituida por:
- Próximo paso:
```
